# Z-Orbit 1.3.0 · 中英文界面

仅支持 Windows 10 / 11 x64。

- 新增简体中文 / English 切换：打开“应用管理”，在右上角选择语言，即时生效并自动保存。
- 英文覆盖轮播操作提示、应用管理、使用说明、托盘菜单和应用自身的提示信息。
- 默认仍为简体中文，首次安装显示完整操作说明。
- 切换语言保留应用名称、地址、图片、排序及未保存的编辑内容。
- 公开版仍提供 Grok、Claude、GPT 三个网页入口。

Windows 自带的文件选择框、系统按钮和系统错误信息仍跟随系统语言。

升级前从系统托盘退出旧版本，再运行安装包；已有个人设置会保留。

[直接下载 Windows 安装包](https://github.com/ZShonz/Z-Orbit/releases/latest/download/Z-Orbit-Setup.exe)

# English

Windows 10 / 11 x64 only.

- Added instant Simplified Chinese / English switching with a saved language preference. Open **应用管理** (Manage apps), then select **English** at the top right.
- Translated launcher hints, app management, usage instructions, tray menus, and app-generated messages.
- Simplified Chinese remains the default, with full operation hints on first use.
- Switching languages preserves app names, addresses, images, order, and unsaved edits.
- Public defaults remain the Grok, Claude, and GPT website entries.

Native Windows dialogs, system buttons, and system error messages follow your Windows language.

Exit the previous version through its tray menu before installing. Existing personal settings are preserved.

[Download the Windows installer](https://github.com/ZShonz/Z-Orbit/releases/latest/download/Z-Orbit-Setup.exe)
