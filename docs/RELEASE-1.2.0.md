# Z-Orbit 1.2.0

首次公开开源发布，仅支持 Windows 10 / 11 x64，界面为中文。

- 头像轮播启动器、默认完整操作说明和可选洁净版。
- 独立应用管理、原图标导入、自定义头像、拖动排序。
- 四套配色、自定义全局快捷键、托盘及开机启动。
- 默认提供 Grok、Claude、GPT 三个网页示例；不包含作者的本地快捷方式。
- GPL-3.0 开源，中英文说明与演示截图见仓库 README。

下载 `Z-Orbit-Setup.exe` 安装。无需单独安装 .NET；退出正在运行的 Z-Orbit 后安装，已有个人设置保留。安装包未签名，可使用 `SHA256SUMS.txt` 核对文件。首次配置开启后台启动，可在管理设置中关闭。

## English

First public open-source release for **Windows 10 / 11 x64 only**. The UI is currently Chinese.

A portrait-carousel launcher with app management, shortcut/icon import, drag sorting, four themes, customizable global hotkeys, clean mode, and tray/startup support. Public defaults include only Grok, Claude, and GPT website entries.

Download `Z-Orbit-Setup.exe`. The .NET runtime is bundled. Exit any running instance before installing; personal settings are preserved. The installer is unsigned; verify its checksum using `SHA256SUMS.txt`. Startup is enabled by default and can be disabled in management. Source is licensed under GPL-3.0.
